# Happy Lunchbox Planner

aplicação de lancheiras saudaveis para a escola. 
- possibilidade de poder ter perfis dos meus filhos de idades diferentes e numero de lanches por dia diferentes
- devo poder definir quais os dias que tem treinos para que os lanches possam ser ajustados/reforçdos
- quero uma secção de receitas, com possibilidade de adicionar receitas manualmente
- plano semanal/mensal por filho ou agregado. Neste plano agregado com todos os filhos deves ajustar os lanches para ser o mesmo para ambos, se for adequado (por exemplo, muffins de banana no mesmo dias para ambas) 
- os lanches devem ser completos (higratos, proteina, fruta...)
- lista de compras gerada para a totalidade do plano que estiver definidafiz este ponto de partida
